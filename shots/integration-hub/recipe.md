# 统一中枢翻面

旧结构变为统一中枢。适用于原文有前后结构变化和实际接入关系。

输入要求：旧/新结构与连接都有证据；以示意图表达，去掉无来源app标志与流量暗示。全部图层通过 slots 绑定真实内容，来源写入 visual.source。

先读旧结构，before 的 focus 执行一次翻面，背面为实际 hub。中枢和外围节点同步进入，节点落定约1/3秒后所有真实路径同时描画。

关键参数：slots.before/hub/items；visual.beforeId/afterId 对应旧/新结构。每个外围节点恰好一条指向 hub 的 connection，不使用无来源应用标志或脉冲流量。

时间预算：入场 → 显式变化或聚焦 → 完成态独立阅读。动作由 beats 给定，秒数按 FPS 换算；入场 0.2–2.8 秒，变化最多 10 秒，完成态至少 1.2 秒。具体可运行分镜见 [公开示例](../../examples/shot-recipes/integration-hub/storyboard.json)。

参数与限制由 [manifest](manifest.json) 与严格 shot schema 共同定义。适配六套当前风格、16:9；示例为自写示意，不作为真实数据。声音不自动生成，制作时用项目统一旁白，不复制上游音效。不得用无来源卡片、统计、关系或素材填空；不接受未经显示的额外图层和动作。
