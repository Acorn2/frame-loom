# 实时曲线写入

数据按顺序揭示与重组。适用于真实序列、分组统计或量级变化。

输入要求：每个变体单独审；时间、单位、基数、轴标可查，禁止编造尖峰和增长。全部图层通过 slots 绑定真实内容，来源写入 visual.source。

采样顺序向前推进，写入端固定在右侧，历史数据向左移动；依照提供数值插值绘线，只显示已取得的采样读数。末值精确对应输入最后一项，结束后静止。

关键参数：samples 包含4–24个唯一短标签与非负 value，单位和来源必填。series 为 metric 图层，其 value 等于末样本。量程来自整组真实数据，最多同时显示最近8项；不生成正弦趋势或人为尖峰。

时间预算：入场 → 显式变化或聚焦 → 完成态独立阅读。动作由 beats 给定，秒数按 FPS 换算；入场 0.2–2.8 秒，变化最多 10 秒，完成态至少 1.2 秒。具体可运行分镜见 [公开示例](../../examples/shot-recipes/chart-live/storyboard.json)。

参数与限制由 [manifest](manifest.json) 与严格 shot schema 共同定义。适配六套当前风格、16:9；示例为自写示意，不作为真实数据。声音不自动生成，制作时用项目统一旁白，不复制上游音效。不得用无来源卡片、统计、关系或素材填空；不接受未经显示的额外图层和动作。
