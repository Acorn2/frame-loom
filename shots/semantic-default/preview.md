# semantic-default 验证记录

基础配方恢复标题与结论入场，公开样片由顺序图解和收尾组成，持续10秒。节点与连线读取显式节拍；图解完成后显示结论，收尾标题和说明先后出现。卡片封面选用图解完成态。

自动检查包含24/30/60fps的基础文字时序、倒序seek、完成态阅读时间、转场职责及生产QA采样；全项目282项测试通过。公开分镜按fast模式验证，样片生成过程检查素材、文本布局和安全区。

[实际关键帧](../../examples/shot-recipes/semantic-default/previews/motion-contact.png)：从左到右、从上到下分别为帧32、75、110、146、189、216。

浏览器已检查卡片自动播放与10秒样片从头到尾的正常速度播放；无解码错误。见[网页复核](../../examples/shot-recipes/semantic-default/previews/browser-review.json)和[逐帧检查](../../examples/shot-recipes/semantic-default/previews/frame-review.json)。

当前示例为retro-zine横屏静音预览。真实TTS、其他风格与竖屏的视觉表现仍须单独验收；未批准为stable或用户成片交付。
