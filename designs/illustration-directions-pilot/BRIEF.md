# 批注图解与情境叙事：独立设计试片

2026-11-13：hresh 确认两条方向，要求先各制作约30秒样片，主题与旁白一致。随后明确本轮先看静音样片，保留相同旁白文本。本轮不接入正式配方，不修改手绘白板、风格库、生产 renderer 或中英文 README，不提交或推送。

## 同一内容，两种表达

标题为“好问题，从观察开始”，情境为亲子观察两片形状不同的叶子。旁白为原创的观察方法示例，不作植物种类鉴定或生物学因果推断；叶片与人物均为虚构的AI原创插画，不能标记为真实采集照片。

两个方向共用五场、同一旁白文本、同一短句字幕与30秒时轴：观察起点、看见细节、比较差异、提出问题、收束方法。

- **批注图解**：叶片是观察对象。使用大幅主体、实际图片局部、绑定可见部位的标记、并置对照与旁注，观众跟着看图理解。
- **情境叙事**：人物与物件构成观察情境。用连续角色、全景／近景与关键姿态切换推进观察、比较、提问，观众跟着场景理解。不把静态图称为角色表演或真实观察记录。

画布1920×1080、30fps。全片文字使用受控思源黑体，字体字节指纹与SIL OFL许可沿用仓库。白／冷灰背景；绿色表达观察，橙红表达当前关注。品牌使用公开占位 Your Brand。字幕直接落在画布上，不加底板；底部独立留区，短句单行显示。

## 素材和复现边界

实际调用原生 imagegen 生成素材，逐张查看后复制到 assets；提示词、来源、字节指纹和复核记录保存在本目录。人物近景以首张情境图为参考，保持角色与服饰一致。只用Remotion已有的显现、描线、聚焦、平移与缩放能力；这是独立设计入口，不扩大生产能力清单。

静音输出、封面、关键帧与设计检查记录保存在 output 的独立修订目录。同源封面从已检查视频取得；检查范围包括文字边界、品牌／字幕安全区、图像可读性、元数据、完整解码及实际播放。设计检查不伪造正式生产 receipt、用户批准或有声交付记录。

确认效果后再讨论版本化配方、兼容路径及风格库更新。现有三套风格和旧项目保持原契约。

## 本地复现

在仓库根目录使用现有依赖：

```bash
node_modules/.bin/tsc --noEmit -p designs/illustration-directions-pilot/tsconfig.json
node --import tsx/esm designs/illustration-directions-pilot/render.mjs --revision=v3
```

新修订目录需不存在；`--phase=stills` 可先检查关键帧，再对相同输入执行 `--phase=video`。输入变化后使用新的修订号，不覆盖已看过的样片。当前候选为 `output/v2/annotated.mp4` 与 `output/v2/narrative.mp4`；本目录 `index.html` 是独立对比播放器。
