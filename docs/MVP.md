# FrameLoom v0.5 MVP

## 用户与问题

独立开发者和使用 Coding Agent 的内容创作者，需要把文档稳定地转成可审阅、可修改、可重复渲染的视频预览，但不希望每次从零搭建时间轴和动画代码。

## 输入、处理与输出

- 输入：Markdown 内容、目标画布、Style Pack 选择，以及经过人工审核的 `storyboard.json`。
- 处理：候选风格筛选、schema/能力/映射/素材/时间轴/安全区校验；Remotion 按 Style Pack token 渲染场景。
- 输出：默认是不包含音频轨的 H.264 视觉预览；可选输出本地音频 pilot；两者均生成元数据报告、代表帧、contact sheet 和 QA 报告。

## 不做什么

v0.5 不做在线编辑器、云端渲染、账号、内置 TTS/声音克隆、素材抓取和自动发布。没有审核的 draft 不允许渲染，自动 QA 也不等于完整播放验收。

## 验收标准

三个公开示例可以独立通过校验、素材溯源和横/竖屏安全区检查；四类语义模板均有示例覆盖；每个 Style Pack 可通过文件契约加载，无需修改核心注册表。20 秒以上视频至少抽取 6 个代表帧并生成 contact sheet。更换同结构文案不需要修改 renderer。
