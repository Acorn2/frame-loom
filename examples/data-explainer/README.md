# Data Explainer Example

竖屏 `scatterbrain` 示例。所有数字只描述示例自身的检查结构。

```bash
npm run validate:storyboard -- examples/data-explainer/storyboard.json
npm run check:safe-area -- examples/data-explainer/storyboard.json
npm run render:storyboard -- examples/data-explainer/storyboard.json /tmp/frame-loom-data-explainer.mp4
npm run extract:review-frames -- /tmp/frame-loom-data-explainer.mp4 examples/data-explainer/storyboard.json /tmp/frame-loom-data-explainer-review
```
