# Script · 20 秒静音视觉预览

字幕只辅助画面阅读，不代表已有旁白音频；镜头时长是视觉预估。

| Scene ID | 建议口播／语义 | 屏幕主句 | 画面工作 |
| --- | --- | --- | --- |
| `opening` | 已有文稿和结构化材料，可以进入可复核的视频制作流程。 | 从材料到可审阅视频 | 给出输入和结果 |
| `process` | 先整理内容与分镜，再校验和渲染，最后查看预览与 QA。 | 内容 → 分镜 → 复核 | 三张纸卡依次出现 |
| `claim` | fast 模式帮助自动检查，但不代表人工审核。 | 自动预览不等于人工审核 | 划清完成状态 |
| `closing` | 自动检查后，仍要完整播放视频再决定是否采用。 | 看完整支视频，再决定采用 | 结论停留 |
