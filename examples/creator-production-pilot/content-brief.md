# Content Brief

## 叙事顺序

1. `opening`：告诉观众这条生产链的输入与结果。
2. `process`：把现有流程压缩成可见的三段：整理材料、分镜与校验渲染、输出复核。
3. `claim`：说明 fast 模式仅代表自动预览，不能替代人工审核。
4. `closing`：留下“完整播放复核”的下一步。

主张、原文位置和 scene ID 见 `shot-map.md`。每镜头只承担一项主要信息工作；更换视觉主题时保持此映射。

## 画面排除项

- 不展示伪造的真实界面、用户数据或完成状态。
- 不把静音样片称为已可发布的视频。
- 不加入来源材料没有提及的效率数字、用户规模或效果承诺。
