# 同一分镜，六套风格

这些公开样片使用[同一份分镜](storyboard.semantic.json)，每条为 1920×1080、30 fps、50.8 秒，共 7 个镜头。它们是实际 Remotion 渲染的静音审片预览，带审片标记；用于比较风格与画面表达。

样片文字讲解 FrameLoom 自身的材料、主张、关系、讲稿和素材流程，没有使用用户私有资料。[文档编排试点](../creator-production-pilot/README.md)另提供原始文档与讲稿、分镜交接材料。
