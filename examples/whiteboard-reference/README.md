# Whiteboard 同内容对照

此目录保留为上游绘制方法的历史对照与回归输入。配方库主样片和开放白板镜头样片已改为[原创亲子观察示例](../whiteboard-original/README.md)，不展示本目录的读书人物或讲稿。

以用户提供的 sample-preview.gif 为视觉基准，复制上游 whiteboard-video 公开示例第一场景的文案与 reader.png；源文件为 trustfuture/simon-skills，按仓库 MIT 许可保留声明。此贴纸由上游生成，并非 FrameLoom 本次新生成。素材来源记录见 asset-manifest.json，许可见 [MIT 声明](../../references/licenses/simon-whiteboard-MIT.txt)。

FrameLoom 采用静态 Remotion renderer 与严格 JSON 分镜，移植开放画布、Rough.js 双线顺序、逐行文字擦出、贴纸擦出、描边／填充阶段及单支铅笔运动。保留独立字体、现有生产指纹、QA、音频和字幕流程；没有导入上游 TTS、发布脚本或任意代码执行。

历史对照样片为20秒、横屏、静音、含场景字幕：`examples/template-families/previews/whiteboard-faithful.mp4`。它复现第一场景的视觉结构，不是将 GIF 直接充作 renderer 产物。自己的文档使用生成素材流程，不复制本示例事实或品牌。
