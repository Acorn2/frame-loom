# 文案优先风格的正式示例

`annotated-reasoning`为批注推演，`editorial-typography`为编辑式排印。两套使用正式注册的镜头、字体加载、字幕、品牌及布局QA，未使用独立实验composition或概念图作为整张背景。

- 各目录的 `storyboard.json`：与原白板一致的“好问题，从观察开始”，18秒，用于网页主展示，保留同一完整旁白文本和画面文字。
- 各目录的 `study-storyboard.json`：已认可的“资料多，不等于讲得清楚”，26秒，逐句字幕的静音对照，文案为主，小插画为辅。
- 原始文案在 `source.md`；素材来源在 `asset-manifest.json`。两套均明确走有来源图像路线，复用原生imagegen实际生成且复核的公开亲子图与实验小插画，不冒充依新规范重新生成。新纯文档生产按[制作指南](../../references/text-led-production.md)实际生图并登记。

公开预览输出位于 `examples/template-families/previews/<style>-text-led.mp4`，封面由同一实际renderer完成态生成。配方库镜头样片使用26秒分镜。原彩色手绘与像素输入保持历史兼容，不批量迁移旧项目。
