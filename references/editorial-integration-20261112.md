## 实施范围

- 新增 `editorial-explainer@1.2.0`，限定 `retro-zine`、16:9；静态注册到现有生产、校验、预检与布局实测流程。
- 五种构图承接试片：问题开场、来源分栏、证据并置、连续重标尺、结论收束。文字、数据、图表及线条几何来自分镜，系统 renderer 不依赖试片文案或 90／100 这组示例数值。
- 图表使用原始数值计算柱高，标签保留原值和统一单位；非零起点必须有可见说明。重标尺显式绑定 `focus`，在柱体入场后连续改变同一组数据的显示范围。
- 支持项目全片字体与现有配色契约，保留底部字幕安全区；当前图表仅支持非负值，数轴边界最多两位小数。
- 配方库的墨白主样片、文章观点数据入口及同源封面使用正式 renderer 产物。自动编排提示推荐新配方，手动集合仍是严格白名单。
- 中英文 README 展示三条正式方向；所有旧风格 ID、旧镜头版本和生产输入路径保持原契约，不迁移旧项目。
