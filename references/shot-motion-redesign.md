# 已接入27份配方动效重做

> 本文记录1.1.0动效改造。当前1.2.0场景外观见[视觉实施矩阵](shot-visual-redesign.md)，运动阶段继续沿用本文方案。

范围：21个上游场景、4个宿主动作、2个换章转场。3个原生场景保留；21个P2候选未接入。

场景与宿主动作升级到1.1.0，旧1.0.0渲染器及清单保留。两个换章转场按上游核对后沿用1.0.0，不为版本号而改变其几何契约。

| 清单 | 配方 | 运动辨识点 |
| --- | --- | --- |
| A01 | `blur-slide@1.1.0` | 中文短语从虚焦中上浮；副标题以更小的位移接入，三通道同步归零。 |
| A02 | `paper-title@1.1.0` | 短语依次压印上纸，原文关键词以斜体强调，最后一笔划线。 |
| A03 | `title-to-label@1.1.0` | 标题先居中站稳，同一曲线缩到左上角；正文在标题完成六成让位时开始生长。 |
| A04 | `lead-word-assemble@1.1.0` | 首个关键词以大字号独占中心，缩回真实行内基线后，余下短语从右侧组句。 |
| A05 | `split-text-stagger@1.1.0` | 短语从各自裁切线下裂升，先越过基线一小段再回落锁定。 |
| A06 | `brace-expand@1.1.0` | 花括号先在中心建立，再弹向两边；文字揭示宽度与括号间距严格绑定。 |
| A07 | `pill-slot-cycle@1.1.0` | 固定句干保持不动，旧内容胶囊向上加速退出，新胶囊从下方减速落位。 |
| A08 | `word-roll@1.1.0` | 固定句干旁的三行词轮滚动，相邻行虚焦，中间行落定才获得强调色。 |
| A09 | `text-column-converge@1.1.0` | 左右文字钉在各自外缘轮换，末项停稳后只合拢一次，再出现可追溯的归纳。 |
| A10 | `evidence-relay@1.1.0` | 等高摘录卡沿胶片带逐格滚动，右侧关键词先退出后换入，卡与词保持中线对齐。 |
| A11 | `list-reveal@1.1.0` | 条目依次从小到实落位，早早变得不透明，落定带一次软过冲。 |
| A12 | `document-conclusions@1.1.0` | 原文先居中阅读，再停靠左侧；三条圆端结论逐条发出，来源持续驻留。 |
| A13 | `card-stack@1.1.0` | 卡片各自弹入中心叠成集合，再共享一次 focus 展开为带深度与倾角的扇面。 |
| A14 | `row-embed@1.1.0` | 内容行从上空降下，透视收平，落位出现短强调缝；可用两次胶带拍定。 |
| A15 | `concept-matrix@1.1.0` | 低密度矩阵先建立暗格，再按格点亮；线框变体先画轮廓、再填入正文，翻面为独立宿主能力。 |
| A16 | `platform-hinge-rise@1.1.0` | 水平平台先建立，两组证据从各自底边支点立入，再把结论从平台下方推出。 |
| A17 | `structure-then-text@1.1.0` | 空结构框从四方装配并描边，闭合后文字进入；描边带可见笔头。 |
| B01 | `source-converge@1.1.0` | 先让来源可读，再描画汇聚路径；代表输入的几何载体沿同一贝塞尔轨迹进入结果。 |
| B05 | `timeline-travel@1.1.0` | 横向世界层沿时间轴逐项行进，事件卡从刻度底边弹立，每项停稳可读。 |
| B08 | `odometer-roll@1.1.0` | 数字各位先连续滚动，再从左到右减速锁定；运动时出现轻残影，停止后清除。 |
| B16 | `diagram-cascade@1.1.0` | 根节点先落定，子层按父子顺序弹出，折角连线与本层节点同步生长。 |
| C01 | `marker-underline@1.1.0` | 文字落定后，一笔由左向右贴着关键词下缘画出，笔形不等宽并微微向右上倾。 |
| C02 | `outline-trace@1.1.0` | 先沿卡片轮廓描边，粗笔头跑在前面，闭合再把正文交给宿主。 |
| C03 | `paper-tape@1.1.0` | 两条撕边胶带依次扑到对角，落地短压扁、旋转过冲再回正；第二条拍下后纸面停止轻晃。 |
| C08 | `card-flip@1.1.0` | 同一张卡以Y轴翻面回答正面的内容，侧棱阴影随角度移动，背面正文平稳落定。 |
| C10 | `blinds-wipe@1.0.0` | 两章各自静止，由12根竖向百叶从左至右错峰交接，接缝随波扫过。 |
| C13 | `bottom-push@1.0.0` | 新章连同底色从底边整体顶入，旧章同速被顶出，接缝阴影提供实体接触感。 |
