# 配方库样片失效回退修复

2026-10-05：此前预览指纹不匹配时，catalog关闭全部动画，并回退到fixture目录的早期完成态、边界图或共用的旧收尾图。这些图仍为米黄色设计，导致页面掩盖样片过期状态。中性外观实现和公开样片文件仍然存在。

当前catalog只使用当前指纹下已完成且非空的封面／动画对；失效时两项均为空，状态为stale或missing。卡片和详情显示“样片待更新”或“样片待生成”，不请求null图片，不借用历史图或其他配方图。说明、ID复制与兼容选择保持可用。发布构建继续拒绝缺失或过期样片。

已按实际renderer重新生成53份公开样片（51份配方及2份变体），通过严格构建。ffprobe检查全部样片为960×540，时长与清单一致；53张封面的联系表已检查。回归测试先复现失败，再修复通过：页面测试43项、类型检查、lint和文档链接检查通过。浏览器实际检查缺失状态的详情与复制、37场景／9辅助／5转场的动画、详情播放、矩阵变体和375px布局。

当前样片与页面的公开复核记录见[视觉复核](../examples/shot-recipes/visual-review/README.md)。
