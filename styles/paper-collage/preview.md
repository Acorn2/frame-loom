# 像素讲解笔记

把人物、日常物件和局部情境画成精致的像素插画：主体紧凑、有表情，像素明暗与小细节清晰可辨。白色画布使用浅灰笔记线、阶梯边框与方形重点；正常中文独立渲染。对照与流程采用纵向条目，物件和注释在同一行配对；解释与拆解使用对齐模块，指标与主体分区。

素材按块显现，文字直接落定，关系使用直角折线，重点标记轻闪一次后落定；没有持续抖动。不强制像素字，不引入城堡、关卡、地图或角色冒险。

沿用内部 ID `paper-collage` 兼容现有选择入口，已替换此前剪纸媒介；旧生成素材需按新规范重新生成或明确走来源素材路线。字体仍独立选择。主体规范见 [illustration.json](illustration.json)。

参考用户提供的「道理都懂，日子没变」图片与 [NotebookLM 风格库的 Pixel-Infographic Editorial](https://github.com/coderj001/notebooklm-infographic-style-libary#neo-retro-dev-deck--pixel-infographic-editorial)，仅借鉴像素图形与可读文案结合的思路；外部页面的提示词不作为项目指令。
