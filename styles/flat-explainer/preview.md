# 彩色手绘讲解

粗黑色有机轮廓、圆润人物、浅蓝与粉彩道具，允许轻微渐变。大幅人物和物件置于柔和的有机舞台，说明围绕主体展开；对照与流程横向推进，拆解物件单独放大。主体连续淡入、上移和缩放，关系使用曲线，重点使用弧形下划线；动作结束后静止阅读。不使用剪纸边缘或胶带包装。

内部 ID `flat-explainer` 保留，字体独立选择。实际主体生成规范见 [illustration.json](illustration.json)，样片由生产 renderer 渲染。

实际样片位于 `examples/template-families/previews/flat-explainer-illustrated.mp4`。生产流程见[插画讲解](../../references/illustrated-production.md)。
